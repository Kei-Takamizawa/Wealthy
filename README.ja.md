# Wealthy

[English](README.md) · 日本語

Wealthyは、日々の支出・収入・財布の残高を記録するiPhone・iPad向けアプリです。レシート読み取り、支出の集計、端末内AIを使った家計管理に対応しています。

## 機能

- カテゴリと財布を使い分けた支出・収入の記録。
- レシートの読み取り、抽出結果の確認、元画像の保存。
- カレンダーでの取引確認とカテゴリ別の支出分析。
- アプリを開いたときに反映される、月ごとの固定収支。
- Apple Foundation Modelsを使った記録についての質問。
- 記録した収支・資産に応じた、少し笑えるお金のアドバイス。
- レシート画像を任意で含められる、記録の書き出し・復元。

## 必要条件

**iOSまたはiPadOS 26.0以降** と **Apple Intelligence対応端末** が必要です。Apple Intelligenceを有効にし、OSモデルの準備が完了してからアプリを利用できます。

| デバイス | 対応ハードウェア |
| --- | --- |
| iPhone | iPhone 15 Pro / Pro Max、iPhone 16以降、iPhone Air |
| iPad | M1以降の搭載モデル、iPad mini（A17 Pro） |

Appleの対応言語・地域も利用条件に含まれます。起動時と前面復帰時に、OSが返すモデルの利用可否を確認します。[Appleの最新の必要条件](https://support.apple.com/ja-jp/121115)も確認してください。

## 使い方

1. **設定 → Apple IntelligenceとSiri** でApple Intelligenceを有効にし、OSモデルの準備が完了するまで待ちます。
2. 初回起動のポップアップで **English** または **日本語** を選びます。選択前の既定表示は英語で、選択結果は保存されます。後から **ホーム → 設定 → 言語設定** で変更できます。
3. 財布を追加し、収入を記録するかレシートを読み取ります。読み取り結果を確認してから保存してください。
4. カレンダーと分析タブで記録を振り返ります。AIアシスタントでは記録について質問できます。

## 端末内AI

チャット、レシート情報の補助抽出、短い支出コメントには、Appleの組み込み **SystemLanguageModel** を使用します。モデルの取得・更新はOSが管理します。モデルのダウンロード画面や選択画面はありません。

チャットの返答言語は、表示言語とは独立して最新の入力に合わせます。英語表示で日本語の質問を入力しても、日本語での回答を要求します。言語を判定できない入力では表示言語を使います。利用できる返答言語は、インストール済みのAppleモデルによって決まります。支出コメントは表示言語に合わせます。短いユーモア部分をAIが作り、記録に応じた行動文を組み合わせます。生成できない場合は端末内の代替文を使います。

推論は端末内で行います。Private Cloud Computeや他のクラウドAIには接続しません。

## 記録・レシート・バックアップ

記録とレシート画像は端末内に保存します。**ホーム → 設定 → データ管理** から、財布、収入、支出、定期収支、カテゴリーをJSON形式で書き出せます。書き出す前に、参照しているレシート画像の合計容量を表示し、画像を含めるか記録のみかを選べます。複数の記録が同じ画像を使う場合は、画像を重複して保存しません。JSONへの格納により画像データの容量は約33%増えます。

復元すると現在の記録を置き換えます。画像付きバックアップは画像の実体も復元しますが、記録のみのファイルから画像は復元できません。旧形式の記録も読み込めますが、含まれていたチャット履歴は無視します。画像が多い場合、書き出し・復元時に多くのメモリが必要です。

**チャット履歴はアプリの書き出しに含めません。** 各メッセージは作成から24時間で期限切れになります。アプリ実行中に削除し、起動時・前面復帰時にも確認します。iOSがアプリを停止・終了している間に期限を迎えた場合、次に動いたときに削除します。期限切れのメッセージは画面表示とAIへの会話入力から除外します。

レシート金額の自動抽出は円の整数金額を対象とし、外貨は手入力が必要です。金額と日付にはAIの推測を使いません。読み取れた印字日付を優先し、印字日付を読み取れない場合はカメラスキャンが戻った時点の日時を仮入力し、編集画面でその旨を表示します。適切な既存カテゴリーを再利用し、該当するものがなければ新しいカテゴリーを作成します。抽出結果は編集できます。

認識は完全ではありません。15枚の開発用サンプルでは、読める円の合計10枚中6枚が一致し、残り4枚は未確定でした。印字日付は14枚中14枚で一致しました。文字・カテゴリーの結果、除外条件、限界は[測定レポート](Verification/ReceiptImageOCR/RESULTS.md)を参照してください。これらの画像は改善にも使ったため、未見のレシートでの精度を保証するものではありません。保存前に必ず内容を確認してください。

## ソースからビルド

iOS 26以降のSDKを含むXcodeが必要です。開発時のビルド確認にはXcode 27.0を使用しています。`Wealthy/Wealthy.xcodeproj` を開き、**Wealthy** スキームと署名チームを設定し、対応するiPhoneまたはiPadで実行してください。Appleのシステムフレームワークを使い、外部Swiftパッケージには依存しません。

Simulatorではビルドを確認できます。Apple Intelligenceの動作は対応する実機での検証が必要です。自動検査と残る実機検証は[検証手順](Verification/README.md)を参照してください。
