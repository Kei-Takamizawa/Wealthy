# Wealthy

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Français](README.fr.md) · [Bahasa Indonesia](README.id.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Português](README.pt.md)

Wealthyは、支出・収入・財布の残高を記録するiPhone・iPad向けアプリです。レシート読み取り、支出集計、端末内AIで家計を振り返れます。

## 機能

- 財布とカテゴリー別の収入・支出の記録。
- レシート読み取り、抽出結果の確認、元画像の保存。
- カレンダーでの取引確認とカテゴリー別の支出分析。
- アプリを開いたときに反映される月ごとの固定収支。
- Apple Foundation Modelsを使った記録についての質問。
- 記録した収支・資産に応じた短いユーモア付きのアドバイス。
- レシート画像を任意で含める記録の書き出し・復元。
- 複数通貨で資産と取引を記録し、残高を通貨ごとに分けて管理。


## 複数通貨

- SIXが2026-09-17に公開した一覧に基づき、**155種類の有効なISO 4217通貨**に対応しています。
- 初回起動時に表示言語を選んだ後、利用する通貨を1つ以上選びます。**ホーム → 設定**で利用通貨を編集し、新規入力の既定通貨を選べます。
- 資産と取引履歴は各記録に保存された通貨で表示します。残高は通貨ごとに分かれ、分析では利用通貨を切り替えられます。自動の為替換算は行いません。
- 金額はISOの最小通貨単位で保存します（小数点以下はJPYが0桁、USDが2桁、KWDが3桁）。既存の記録は引き続きJPYです。
- レシートOCRの対象は従来どおり日本語・英語の文字と整数のJPY金額です。外貨金額は手入力し、内容を確認してください。

## 支払い方法とポイントカード

レシートに記載された支払い方法に対応する財布を提案し、記載がなければ現金を使います。保存確定時に一度だけ減額します。財布が未登録なら残高0円で自動作成し、支出をマイナス残高で表示します（例：`¥0 → ¥-1,200`）。記録の編集・削除では財布残高も調整します。複数の支払い方法、ポイント利用、該当する財布が複数ある場合は手動確認が必要です。OCR文字列からのルール判定であり、撮影画像での支払い方法の精度は未測定です。

**財布**画面では、自動作成された財布を編集して現在残高を設定できます。また、初期残高を入力して登録すると記録済み残高に加算します。ポイントカードは名前、任意の会員番号、ポイント残高、任意の有効期限を登録できます。ポイントは手入力で管理し、金銭の資産合計に含めず、金融記録のバックアップには含めます。

銀行・決済サービスの残高自動同期は**未実装**です。最初の連携候補はSBI新生銀行とドコモSMTBネット銀行（旧・住信SBIネット銀行）です。銀行アプリを開く許可だけでは残高を読めず、承認された残高共有サービスが必要です。提供元の利用条件と想定する認可操作は[連携の調査資料](Documentation/FinancialServiceIntegration.md)に記載しています。

## 必要条件

**iOSまたはiPadOS 26.0以降** と **Apple Intelligence対応端末** が必要です。Apple Intelligenceを有効にし、OSモデルの準備が完了してからアプリを利用できます。

| デバイス | 対応ハードウェア |
| --- | --- |
| iPhone | iPhone 15 Pro / Pro Max、iPhone 16以降、iPhone Air |
| iPad | M1以降の搭載モデル、iPad mini（A17 Pro） |

Appleの言語・地域制限も適用されます。起動時と前面復帰時にモデルの利用可否を確認します。[Appleの最新の必要条件](https://www.apple.com/jp/apple-intelligence/)を参照してください。

## 使い方

1. **設定 → Apple IntelligenceとSiri** でApple Intelligenceを有効にし、モデルの準備が完了するまで待ちます。
2. 初回起動のポップアップで **11の表示言語** から選びます。既定表示は英語で、選択結果は保存されます。後から **ホーム → 設定 → 言語設定** で変更できます。アラビア語は右から左の画面表示になります。
3. 利用する通貨を1つ以上選びます。利用通貨と新規入力の既定通貨は、後から **ホーム → 設定** で変更できます。
4. 財布を追加し、収入を記録するかレシートを読み取ります。保存前に抽出結果を確認してください。
5. カレンダーと分析タブで記録を振り返り、AIアシスタントで記録について質問できます。

表示言語は英語、日本語、簡体字中国語、ヒンディー語、スペイン語、アラビア語、フランス語、インドネシア語、韓国語、ロシア語、ポルトガル語です。これは画面とREADMEの対応言語であり、インストール済みのApple AIモデルが11言語すべてに対応することを意味しません。

## 端末内AI

チャット、レシート情報の補助抽出、短い支出コメントにはAppleの組み込み **SystemLanguageModel** を使います。モデルと更新はOSが管理します。他のモデル、モデルのダウンロード・選択画面、Private Cloud Computeや他のクラウドAIへの接続はありません。

チャットは表示言語と独立して、最新の入力言語での回答を要求します。入力言語を判定できない場合は表示言語を使います。対応言語はインストール済みのAppleモデルに依存します。未対応の言語では明示的なメッセージを表示するので、そのモデルの対応言語で入力してください。支出コメントは表示言語を指定し、AIの短い冗談と記録に基づく行動文を組み合わせます。生成できない場合は端末内の代替アドバイスを使います。

## 記録・レシート・バックアップ

記録とレシート画像は端末内に保存します。**ホーム → 設定 → データ管理** から財布、収入、支出、定期収支、カテゴリーをJSON形式で書き出せます。ポップアップに参照画像の容量を表示し、画像を含めるか記録のみかを選べます。共有画像は一度だけ格納します。JSONへの格納で画像データの容量は約 **33%** 増えます。

復元すると現在の記録を置き換えます。画像付きバックアップは元の画像データも復元しますが、記録のみのファイルから画像は復元できません。旧形式の記録も読み込めますが、含まれていたチャット履歴は無視します。画像が多い場合は書き出し・復元に多くのメモリが必要です。

**チャット履歴はすべての書き出しから除外します。** 各メッセージは作成から **24時間** で期限切れになります。実行中に削除し、起動時・前面復帰時にも確認します。iOSがアプリを停止・終了している場合は、次に動いたときに削除します。期限切れのメッセージは表示とAIへの会話入力から除外します。

レシートOCRは **日本語と英語の文字** を対象とします。金額の自動抽出は **円の整数金額** が対象で、外貨は手入力が必要です。金額と日付にはAIの推測を使いません。読める印字日付を使い、読めない場合は認識前のカメラスキャンが戻った時点の日時を仮入力し、確認対象として表示します。適切な既存カテゴリーを再利用し、必要なら新しいカテゴリーを作成します。抽出結果はすべて編集できます。

iOS 27.2のiPhone 16 Pro Maxで、開発にも使った**同じ15枚の画像**を測定した結果、読める円の合計は **6/10** で一致し、残り4枚は未確定でした。印字日付は **14/14**、ハイブリッド分類はラベル付き14件で **14/14** でした。評価対象行の文字誤り率は引き続き **11.22%** です。開発にも使った画像による測定であり、未見データの評価や新しいレシートの精度推定ではありません。macOSでの過去の測定、除外条件と詳細は[測定レポート](Verification/ReceiptImageOCR/RESULTS.md)を参照してください。保存前に必ず結果を確認してください。

## ソースからビルド

**iOS 26以降のSDK** を含むXcodeを使ってください。開発時のビルド確認には **Xcode 27.0** を使用しています。`Wealthy/Wealthy.xcodeproj` を開き、**Wealthy** スキームと署名チームを設定し、対応するiPhoneまたはiPadで実行してください。Appleのシステムフレームワークを使い、外部Swiftパッケージには依存しません。

iOS 27.2のiPhone 16 Pro Maxで、日本語・英語のAI返信と、支出・ウォレット・ポイントカードのローカル操作、およびバックアップダイアログを実機確認しました。他のデバイスと未確認のワークフローは未検証です。[検証手順](Verification/README.md)を参照してください。

**v0.1.1 Pre-release**には、ここで説明したソースコードが含まれます。署名済みアプリの配布はありません。ビルド前に上記の検証範囲と制限を確認してください。
