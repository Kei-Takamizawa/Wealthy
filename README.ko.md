# Wealthy

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Français](README.fr.md) · [Bahasa Indonesia](README.id.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Português](README.pt.md)

Wealthy는 지출, 수입, 지갑 잔액을 기록하는 iPhone 및 iPad 앱입니다. 영수증 스캔, 지출 요약, 기기 내 AI로 재정 기록을 살펴볼 수 있습니다.

## 기능

- 지갑과 카테고리별 수입·지출 기록.
- 영수증 스캔, 추출 결과 확인, 원본 이미지 보관.
- 달력에서 거래 확인 및 카테고리별 지출 분석.
- 앱을 열 때 월별 반복 내역 반영.
- Apple Foundation Models에 기록 관련 질문.
- 기록된 수입·지출·자산에 기반한 짧고 가벼운 유머가 있는 조언.
- 영수증 이미지를 선택적으로 포함한 재정 기록 내보내기·복원.
- 여러 통화로 자산과 거래를 기록하고 통화별 잔액을 분리해 관리합니다.


## 여러 통화

- 2026-09-17에 게시된 SIX 목록을 기준으로 **155개의 활성 ISO 4217 통화**를 지원합니다.
- 첫 실행에서 표시 언어를 선택한 다음 사용할 통화를 하나 이상 선택합니다. 이후 **홈 → 설정**에서 활성 통화를 편집하고 새 항목의 기본 통화를 선택할 수 있습니다.
- 자산과 거래 내역은 각 기록에 저장된 통화를 유지합니다. 잔액은 통화별로 분리되며 분석에서 활성 통화 간 전환할 수 있습니다. 자동 환전은 하지 않습니다.
- 금액은 ISO 보조 통화 단위로 저장하며, 소수 자릿수는 JPY 0자리, USD 2자리, KWD 3자리입니다. 기존 기록은 계속 JPY로 유지됩니다.
- 영수증 OCR 범위는 그대로입니다. 일본어·영어 텍스트와 정수 JPY 금액을 자동 추출하며, 외화 금액은 직접 입력하고 확인해야 합니다.

## 결제 방법과 포인트 카드

영수증에 인쇄된 결제 방법에 맞는 지갑을 제안하며, 표시가 없으면 현금을 사용합니다. 저장을 확정할 때 한 번만 차감합니다. 지갑이 없으면 잔액 0으로 자동 생성하여 마이너스를 표시합니다(예: `¥0 → ¥-1,200`). 기록을 수정하거나 삭제하면 잔액도 조정됩니다. 여러 결제 방법, 포인트 사용 또는 여러 지갑이 일치하면 직접 확인해야 합니다. OCR 텍스트 규칙에 기반하며 촬영 영수증의 결제 방법 정확도는 측정하지 않았습니다.

**지갑**에서 자동 생성된 지갑의 현재 잔액을 수정하거나, 초기 잔액을 등록하여 기록된 잔액에 더할 수 있습니다. 포인트 카드는 이름, 선택적 회원 번호, 포인트 잔액 및 선택적 유효 기간을 등록합니다. 포인트는 직접 입력하며 금전 자산과 분리되고 금융 백업에 포함됩니다.

은행·결제 서비스의 잔액 자동 동기화는 **구현되지 않았습니다**. 첫 연동 후보는 SBI Shinsei Bank와 DOCOMO SMTB Net Bank(구 SBI Sumishin Net Bank)입니다. 은행 앱을 여는 권한만으로 잔액을 읽을 수 없으며 승인된 계좌 공유 서비스가 필요합니다. [연동 검토 자료](Documentation/FinancialServiceIntegration.md)를 확인하세요.

## 요구 사항

**iOS 또는 iPadOS 26.0 이상** 및 **Apple Intelligence 지원 기기**가 필요합니다. Apple Intelligence를 활성화하고 시스템 모델 준비가 끝나야 앱을 사용할 수 있습니다.

| 기기 | 지원 하드웨어 |
| --- | --- |
| iPhone | iPhone 15 Pro / Pro Max, iPhone 16 이후 모델 또는 iPhone Air |
| iPad | M1 이상 탑재 모델 또는 A17 Pro 탑재 iPad mini |

Apple의 언어·지역 제한도 적용됩니다. Wealthy는 시작 시와 포그라운드 복귀 시 모델 사용 가능 여부를 확인합니다. [Apple의 최신 요구 사항](https://www.apple.com/apple-intelligence/)을 참고하세요.

## 사용 방법

1. **설정 → Apple Intelligence 및 Siri**에서 Apple Intelligence를 켜고 모델 준비 완료를 기다립니다.
2. 첫 실행 팝업에서 **11개 표시 언어** 중 하나를 선택합니다. 기본값은 영어이며 선택은 저장됩니다. 이후 **홈 → 설정 → 언어 설정**에서 변경할 수 있습니다. 아랍어 인터페이스는 오른쪽에서 왼쪽으로 표시됩니다.
3. 사용할 통화를 하나 이상 선택합니다. 활성 통화와 새 항목의 기본 통화는 나중에 **홈 → 설정**에서 변경할 수 있습니다.
4. 지갑을 추가하고 수입을 기록하거나 영수증을 스캔합니다. 저장 전에 인식된 내용을 확인하세요.
5. 달력과 분석 탭을 살펴보거나 AI 도우미에 기록 관련 질문을 하세요.

표시 언어는 영어, 일본어, 중국어 간체, 힌디어, 스페인어, 아랍어, 프랑스어, 인도네시아어, 한국어, 러시아어, 포르투갈어입니다. 인터페이스와 README의 지원 목록이며, 설치된 Apple AI 모델이 11개 언어를 모두 지원한다는 뜻은 아닙니다.

## 기기 내 AI

채팅, 영수증 정보의 보조 추출, 짧은 지출 코멘트에는 Apple 내장 **SystemLanguageModel**을 사용합니다. 운영체제가 모델과 업데이트를 관리합니다. 다른 모델, 모델 다운로드·선택 화면, Private Cloud Compute나 다른 클라우드 AI 연결은 없습니다.

채팅은 표시 언어와 무관하게 가장 최근 메시지의 언어로 답변을 요청합니다. 입력 언어를 판단하지 못하면 표시 언어를 사용합니다. 지원 언어는 설치된 Apple 모델에 따라 다릅니다. 지원하지 않는 채팅 언어에는 명확한 안내가 표시되므로 해당 모델이 지원하는 언어로 입력하세요. 지출 코멘트는 표시 언어를 요청하고 AI의 짧은 농담과 기록에 따른 행동 제안을 결합합니다. 생성이 불가능하면 로컬 대체 조언을 사용합니다.

## 기록·영수증·백업

재정 기록과 영수증 이미지는 기기에 저장됩니다. **홈 → 설정 → 데이터 관리**에서 지갑, 수입, 지출, 반복 내역, 카테고리를 JSON으로 내보낼 수 있습니다. 팝업에서 참조 이미지의 크기를 확인하고 이미지 포함 또는 기록만 내보내기를 선택합니다. 공유 이미지는 한 번만 포함됩니다. JSON 인코딩으로 이미지 데이터 크기가 약 **33%** 늘어납니다.

복원은 현재 기록을 대체합니다. 이미지 포함 백업은 원본 이미지 데이터를 복원하지만 기록만 있는 백업은 이미지를 복원할 수 없습니다. 이전 형식 백업도 읽을 수 있으나 포함된 채팅 기록은 무시됩니다. 이미지가 많으면 내보내기·복원에 많은 메모리가 필요할 수 있습니다.

**모든 내보내기에서 채팅 기록을 제외합니다.** 메시지는 생성 후 **24시간**에 만료됩니다. Wealthy는 실행 중 만료 메시지를 삭제하고 시작·포그라운드 복귀 시 확인합니다. iOS가 앱을 일시 중단하거나 종료하면 다음 실행 시 삭제합니다. 만료된 메시지는 화면 및 AI 대화 맥락에서 제외됩니다.

영수증 OCR은 **일본어와 영어 텍스트**를 대상으로 합니다. 금액 자동 추출은 **정수 단위 일본 엔화**에 한정되며 외화는 수동 입력이 필요합니다. 금액과 날짜는 AI 추측이 아닌 OCR 파서에서 가져옵니다. 읽을 수 있는 인쇄 날짜를 쓰고, 없으면 인식 시작 전 카메라 스캔이 반환된 시점의 날짜를 넣어 확인 대상으로 표시합니다. 적절한 기존 카테고리를 재사용하고 필요하면 새 카테고리를 만듭니다. 추출된 모든 내용은 수정할 수 있습니다.

iOS 27.2를 실행하는 iPhone 16 Pro Max에서 개발에 사용한 **같은 이미지 15장**으로 측정한 결과, 읽을 수 있는 엔화 합계는 **6/10** 일치했고 나머지 4개는 미확정이었습니다. 인쇄 날짜는 **14/14**, 하이브리드 카테고리는 **라벨이 있는 14개 샘플 중 14/14** 일치했으며, 선택한 텍스트 줄의 문자 오류율은 **11.22%**로 동일했습니다. 이 이미지들은 개발에도 사용되었으므로 독립 평가 결과나 새 영수증의 정확도 추정이 아닙니다. macOS 과거 측정, 제외 조건과 자세한 내용은 [측정 보고서](Verification/ReceiptImageOCR/RESULTS.md)를 참고하세요. 저장 전에 반드시 확인하세요.

## 소스에서 빌드

**iOS 26 이상 SDK**가 포함된 Xcode를 사용하세요. 개발 빌드는 **Xcode 27.0**에서 확인합니다. `Wealthy/Wealthy.xcodeproj`를 열고 **Wealthy** 스킴과 서명 팀을 설정한 후 호환 iPhone 또는 iPad에서 실행하세요. Apple 시스템 프레임워크를 사용하며 외부 Swift 패키지 의존성은 없습니다.

iOS 27.2를 실행하는 iPhone 16 Pro Max 실기기에서 일본어·영어 AI 답변과 로컬 지출, 지갑, 포인트 카드 작업 및 백업 대화상자를 확인했습니다. 다른 기기와 테스트하지 않은 워크플로는 아직 검증되지 않았습니다. [검증 안내](Verification/README.md)를 참고하세요.

**v0.1.1 사전 릴리스**에는 여기에 설명한 소스 코드가 포함됩니다. 서명된 앱 다운로드는 제공하지 않습니다. 빌드 전에 위의 검증 범위와 제한을 확인하세요.
